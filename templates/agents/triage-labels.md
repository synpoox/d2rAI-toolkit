# Triage labels

The five canonical triage roles and the label string this repo uses for each. Edit the second column if the
repo's vocabulary differs; skills that name a role use the string from this table.

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | Maintainer evaluation needed |
| needs-info | needs-info | Waiting on reporter information |
| ready-for-agent | ready-for-agent | Fully specified for an agent |
| ready-for-human | ready-for-human | Requires human implementation (including a game check an agent could not finish) |
| wontfix | wontfix | Will not be actioned |
