# Domain docs

## Before exploring

Single-context layout (paths from `[project].glossary` and `[project].adr_dir`):

- `GLOSSARY.md` at the repo root defines domain vocabulary.
- `docs/adr/` holds architecture decisions.

Read the glossary and the ADRs relevant to the work. If absent, proceed silently.

## Vocabulary

Use glossary terms in issue titles, proposals, hypotheses and tests. When a needed concept is missing, reconsider
the wording or note the gap.

## Decisions

Name any proposal that contradicts an existing ADR, with its identifier and the reason to reconsider it.
